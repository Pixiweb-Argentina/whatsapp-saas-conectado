# Arquitectura de información

Navegación propuesta: Inicio, Chats, Automatizaciones, Configuración; acceso Agencia/Workspaces según rol. Conservar Analisis y las capacidades actuales. Contactos/Oportunidades se muestran primero en ficha del inbox y vistas vinculadas de CRM; no agregar un CRM completo independiente.

Configuración: Canales (WA, Instagram, Facebook, Web) → cuentas; Agentes y conocimiento; CRM (HighLevel/HubSpot/Brevo); Equipo; opciones actuales. Cada sección conserva subcomponentes existentes que funcionan.

Automatizaciones: Por defecto → canal/cuenta → fuentes → reglas → detalle de versión/ejecuciones. Las fuentes de la captura se mapean a 14 entradas, con estados: disponible, requiere conexión, requiere permiso, pendiente de prueba o no compatible.

Jerarquía constante: workspace → canal/cuenta → conversación → contacto. Selector de workspace nunca se oculta detrás de otro negocio. Las rutas actuales se conservan; nuevos espacios se implementan dentro del layout existente y se definen en F2/F4, sin URLs inventadas funcionando hoy.

Acceso por rol: admin conecta/elige CRM; manager administra reglas con grant; agent atiende y edita datos permitidos; viewer lee. El servidor valida todas las acciones.
