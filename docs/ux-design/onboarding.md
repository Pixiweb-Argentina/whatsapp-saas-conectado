# Onboarding

Reusar login/alta y selección de workspace existentes. Primer objetivo: recibir una conversación válida, no completar un tour.

1. Confirmar negocio y rol.
2. Mostrar WhatsApp actual conservado y opciones de conectar Instagram/Facebook/Web.
3. Meta: requisitos profesionales/Página → OAuth → elegir activos → revisar permisos → recibir mensaje/comentario de prueba → listo.
4. Proponer regla «Comentá hola» con campos vacíos de publicación/texto/enlace; no inventar una guía ni enviar al activar un borrador.
5. Simular → revisar → activar para eventos futuros.
6. Brevo: key write-only → probar cuenta → seleccionar listas/pipeline/atributos → previsualizar carga inicial → activar sync.
7. Widget: definir dominios → copiar snippet → comprobar sesión de prueba → abrir inbox.

Brevo y widget pueden configurarse más tarde; una cuenta con permisos incompletos no inutiliza WhatsApp. «Listo para pruebas» se distingue de autorización productiva para clientes externos.
